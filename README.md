## FAQ

### What is XCutors?

XCutors is a collection of popular Windows desktop Roblox script executors bundled with a universal loader for running Lua scripts in Roblox games.

### Is XCutors free to use?

Yes, XCutors is free and open-source. However, some individual executors included (like Synapse Z) may require separate licenses.

### Are these tools safe and legal?

XCutors are tools for educational and customization purposes. Use responsibly and only on games you own or have permission to modify. Always respect Roblox's Terms of Service.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11. Administrator privileges may be required for injection.

### How do I update to the latest version?

The loader checks for updates automatically. You can also manually download the latest release from our GitHub repository and replace the existing files.

### Can I use multiple executors at the same time?

No, you should only use one executor at a time. The universal loader makes switching between them seamless.

### Where can I find scripts to run?

XCutors includes a built-in library of popular scripts. You can also load your own .lua files or find community scripts on trusted forums.

### What should I do if injection fails?

Ensure Roblox is running, try running XCutors as administrator, check that your anticomponent isn't blocking it, or refer to our troubleshooting guide in the documentation.
